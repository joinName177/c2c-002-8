# c2c-002 · 情绪植物园

Vue 3 + TypeScript + Vite 纯前端情绪记录与虚拟植物花园。每日记录情绪会种下一株对应植物，连续记录让植物从种子、发芽、开花到结果；断签后保留枯萎标本，并提供生长时间轴和情绪生态年报。数据保存在浏览器 `localStorage`。

## 多花园档案

支持创建多个花园档案（工作焦虑、生活平静……分园打理），每个档案的记录、植物、连续天数与年报彼此独立：

- 首页顶部下拉切换或在「管理档案」面板中切换，花园、时间轴、标本馆、年报全部从当前档案重新取数，顶部计数同步更新；新增记录只落到当前档案。
- 首次打开时自动把已有单花园数据整体迁入名为「我的花园」的默认档案（旧存储键保留为备份），不丢任何一条记录。
- 删除当前正在使用的档案时先自动切到另一个档案再删；只剩最后一个档案时禁止删除，保证任何时刻都有可用的当前档案。

## 分层

- 核心层 `src/core`：情绪记录、连续天数、植物生长阶段、枯萎判断、生态年报、花园档案簿（`profiles.ts`）
- 端口层 `src/ports`：花园快照仓储接口
- 适配器层 `src/adapters`：浏览器本地存储实现
- 界面层 `src/ui`：Vue 页面与原生 CSS 视图
